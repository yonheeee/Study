## Supabase

- 애플리케이션의 백엔드 기능을 묶어서 제공하는 플랫폼
- PostSQL DB, 자동 생성 API, 인증(Auth), Storage, Realtime, Edge Functions의 기능을 사용 가능
```
┌─────────────────────────┐
│        Supabase         │
│                         │
│ PostgreSQL → 데이터     │
│ Auth       → 로그인     │
│ Storage    → 파일       │
│ Realtime   → 실시간     │
│ Functions  → 서버 로직  │
│ API        → 데이터 접근│
└─────────────────────────┘
```
- 백엔드에서 반복적으로 만들어야 하는 기능을 직접 처음부터 구축하지 않고, 빠르게 가져다 쓰는 것

</br>

### 장점
**개발속도**
- 백엔드를 만들지 않고, MVP, 사내 업무 시스템, 스타트업 초기 서비스, 관리자 페이지, 간단한 SaaS처럼 빨리 만들어서 검증해야하는 프로젝트에 적합</br>

**프론트엔드에서 데이터 관리**

- RLS(Row Level Security)로 DB행 단위로 접근 권한을 설정하여 노출되는 데이터에 권한 정책을 사용</br>

**인프라 관리 부담 줄어듬**

- Supabase의 관리형 플랫폼을 사요하여 백엔드 기능 상당 부분 플랫폼이 제공

### 단점

**플랫폼에 의존**
- PostgreSQL을 중심으로 설계되어 있고, 서비스가 커지면 백엔드 서버나 추가 인프라가 필요해질 수 있음</br>
- 잘못 설계 시, 비즈니스 로직이 분산될 수 있음</br>

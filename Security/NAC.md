# NAC

## 풀네임

**NAC — Network Access Control(네트워크 접근 제어)**

회사 네트워크에 접속하려는 **사용자와 기기를 확인하고, 보안 정책에 따라 접속을 허용·차단·격리하는 보안 체계**이다.

## 핵심 개념

NAC는 특정 프로그램 하나의 이름이 아니라 네트워크 접근을 통제하는 **시스템 또는 기술 분야의 명칭**이다.

직원 PC에 설치된 프로그램만을 뜻하지 않으며, 일반적으로 다음 요소가 함께 작동한다.

- **NAC Agent:** 직원 PC의 백신, 보안 업데이트 등 단말 상태를 점검하는 프로그램
- **NAC 관리 서버:** 검사 결과와 회사 정책을 비교하여 접속 허용 여부를 판단하는 서버
- **관리자 화면:** 전산 담당자가 접속 기기와 정책을 관리하는 화면
- **인증 정보:** 접속하는 사용자와 기기의 신원을 확인하는 정보
- **네트워크 장비:** NAC의 판단에 따라 실제 통신을 허용하거나 차단하는 스위치·무선 장비 등

방화벽, 백신, VPN 등의 보안 시스템은 NAC와 연동할 수 있지만, 그 자체가 모두 NAC에 포함되는 것은 아니다.

## 동작 과정

```text
PC가 회사 네트워크에 접속 시도
              ↓
사용자와 기기 정보 확인
              ↓
백신·보안 업데이트·회사 보안 프로그램 등 점검
              ↓
회사에서 정한 보안 정책과 비교
              ↓
접속 허용 / 제한 / 차단 / 격리
```

## NAC가 확인할 수 있는 항목

- 회사에서 허가한 기기인지
- 정상적인 사용자가 접속한 것인지
- 백신이 설치되어 정상 실행 중인지
- 운영체제와 프로그램의 보안 업데이트가 적용되었는지
- 회사에서 요구하는 보안 프로그램이 설치되어 있는지
- 악성코드 감염 또는 보안상 위험이 있는지

## 검사 결과에 따른 처리 예시

| 상황 | 처리 예시 |
|---|---|
| 정상적인 회사 PC | 사내망과 인터넷 접속 허용 |
| 백신이 꺼진 회사 PC | 보안 조치 안내 또는 제한된 네트워크로 격리 |
| 허가되지 않은 개인 PC | 사내망 접속 차단 |
| 방문자 기기 | 사내망은 차단하고 방문자용 인터넷만 허용 |
| 감염이 의심되는 PC | 다른 PC로 확산되지 않도록 네트워크에서 격리 |

## 실무에서 사용하는 표현

### “NAC를 설치해 주세요.”

일반적으로 직원 PC에 **NAC Agent 프로그램을 설치해 달라**는 의미이다.

### “NAC를 도입합니다.”

회사 네트워크에 NAC 서버, 관리정책, Agent와 네트워크 장비 연동 등을 포함한 **접근제어 시스템 전체를 구축한다**는 의미이다.

### “NAC에 등록해 주세요.”

새 PC나 장비의 정보를 등록하여 회사 네트워크에 접속할 수 있도록 승인해 달라는 의미이다.

### “NAC에서 차단됐습니다.”

사용자·기기 인증 실패 또는 보안 정책 미충족으로 네트워크 접속이 거부되었다는 의미이다.

## 관련 기술과 차이

| 기술 | 주요 역할 |
|---|---|
| NAC | 어떤 사용자와 기기가 회사 네트워크에 들어올 수 있는지 통제 |
| VPN | 외부에서 회사 내부망으로 안전하게 연결 |
| 방화벽 | 네트워크 사이에서 허용하거나 차단할 통신을 통제 |
| 백신·EDR | PC 내부의 악성코드와 이상 행동을 탐지·차단 |

NAC 자체가 악성코드를 치료하는 프로그램은 아니다. 백신 상태 등 단말의 보안 상태를 확인하고, 문제가 있는 기기의 네트워크 접속을 제한하는 역할에 가깝다.

## 관련 용어

- **Agent:** 사용자 PC에 설치되어 단말 상태를 검사하고 서버와 통신하는 프로그램
- **Policy(정책):** 접속을 허용하거나 차단하기 위해 회사에서 정한 기준
- **Authentication(인증):** 사용자나 기기의 신원을 확인하는 과정
- **Quarantine(격리):** 문제가 있는 기기를 일반 사내망과 분리하는 조치
- **MAC Address:** 네트워크 기기를 식별할 때 사용하는 주소
- **802.1X:** 사용자나 기기를 인증한 뒤 네트워크 접속을 허용하는 표준 방식

## 한 줄 정리

> NAC는 회사 네트워크에 들어오려는 사용자와 기기를 검사하고, 보안 정책에 따라 접속을 허용하거나 차단하는 네트워크 보안 시스템이다.

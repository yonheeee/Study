## CSP

- CSP(Cloud Service Provider, 클라우드 서비스 제공제)로 서버, 저장공간, 네트워크 같은 IT 인프라 인터넷을 통해 빌려주는 회사</br>
  
  - ex) AWS, Google Cloud, NAVER Cloud</br>

**<일반 회사>**
```
[직접 구축]

회사
 ↓
서버 구매
 ↓
데이터센터에 설치
 ↓
네트워크 구성
 ↓
OS 설치
 ↓
서비스 운영
```
</br>

**<CSP 이용 서비스>**

```
[클라우드 사용]

회사
  │
  ▼
AWS / Azure / GCP   ← CSP
  │
  ├─ 가상 서버
  ├─ 저장공간
  ├─ 네트워크
  ├─ 데이터베이스
  └─ 각종 클라우드 서비스
```
</br>

### CSP를 사용하는 이유
- CSP가 없는 회사의 경우 서버장비 구매, 서버실 설치, 네트워크 구성, OS 설치, 보안 설정 등 **초기 비용과 시간이 많이 필요**하다
- CSP를 사용하면 **컴퓨팅 자원을 직접 소유하지 않고 필요한 만큼 빠르게 빌려 사용**할 수 있다

#### 장점
- 클라우드를 사용할 경우 상황에 따라 서버 자원을 늘렸다가 줄였다가 가능

    - **탄력성**이 좋다고 하며, 서버의 수를 조절하도록 구성하는 **Auto Scaling에도 많이 사용**

#### 단점
- 비용 관리의 어려움

    - FinOps, 비용 모니터링 리소스 최적화 중요
- CSP의 의존성이 발생할 수 있음
    
    - AWS 전용 서비스로 설계했다면, 자체 데이터센터로 옮기려고 한다면 상당한 수정이 필요

        - 이러한 문제를 **Vendor Lock-in(벤더 종속)**이라고 함
